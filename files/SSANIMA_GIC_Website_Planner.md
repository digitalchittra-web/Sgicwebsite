## 🎯 DESIGN PHILOSOPHY

### Target Aesthetic
- **Modern & Professional** - Trust-building, corporate feel
- **Clean & Minimalist** - Avoid clutter, focus on clarity
- **User-Centric** - Easy navigation, clear CTAs
- **Dynamic & Engaging** - Smooth animations, interactive elements
- **Mobile-First** - Responsive across all devices

### Color Palette
- **Primary Color:** Deep Blue (#0F4C8B) - Trust, stability
- **Secondary Color:** Vibrant Orange (#FF6B35) - Energy, action
- **Accent Color:** Teal (#4ECDC4) - Modern, fresh
- **Neutrals:** Light grays and whites for backgrounds
- **Text:** Dark charcoal for readability

### Typography
- **Display Font:** Bold, modern sans-serif for headings (e.g., Poppins, Inter)
- **Body Font:** Clean, readable sans-serif for content (e.g., Segoe UI, Open Sans)

### Buttons & CTAs
- **Primary Button** (Solid blue with white text)
  - "Buy Policy" | "Get Started" | "Get Quote"

  - "Learn More" | "Explore Products"

- **Product Cards** (Icon + Title + Description + CTA)

- **Feature Cards** (Icon + Title + Description, hover effects)
- **Team Cards** (Photo + Name + Title + Brief Bio)

### Forms
- Clean, minimal form design

- Error validation messages

- Progress indicators for multi-step forms

### Images & Media
- **Hero Images:** High-quality, relevant to insurance/protection

- **Team Photos:** Professional headshots

- Smooth page transitions
