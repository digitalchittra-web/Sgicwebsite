## 🎬 ANIMATION & TRANSITIONS

### General Transitions
```
Default: all 0.3s ease
Fast: all 0.15s ease
Slow: all 0.5s ease
```

### Common Animations

**Fade In**
```
From: opacity 0
To: opacity 1
Duration: 0.6s
Timing: ease-out
Usage: Page load, content reveal
```

**Slide In (Left)**
```
From: transform translateX(-50px), opacity 0
To: transform translateX(0), opacity 1
Duration: 0.8s
Timing: ease-out
Usage: Hero text, important elements
```

**Slide In (Up)**
```
From: transform translateY(30px), opacity 0
To: transform translateY(0), opacity 1
Duration: 0.6s
Timing: ease-out
Usage: Cards, sections on scroll
```

**Scale**
```
From: transform scale(0.95)
To: transform scale(1)
Duration: 0.3s
Timing: ease-out
Usage: Button press, card interaction
```

**Hover Effects**
```
Lift: transform translateY(-2px to -5px)
Duration: 0.3s
Usage: Cards, buttons on hover
```

### Stagger Animation (Multiple Elements)
```
Animation Delay: nth-child(n) * 0.1s
Example:
  Element 1: animation-delay: 0s
  Element 2: animation-delay: 0.1s
  Element 3: animation-delay: 0.2s
  Element 4: animation-delay: 0.3s
```

### Scroll Trigger Animation
```
Intersection Observer with threshold: 0.1
Animation trigger: When element enters 50px from bottom
Unobserve after animation plays once
Usage: Cards, feature lists, stats
```

## ♿ ACCESSIBILITY SPECIFICATIONS

### Color Contrast
```
Text vs Background: Minimum 4.5:1 ratio (WCAG AA)
Large Text: Minimum 3:1 ratio
Links: Must be distinguishable from text
Icons: Sufficient contrast ratio required
```

### Typography
```
Minimum Font Size: 16px body text
Line Height: 1.5 or greater
Letter Spacing: Normal or increased slightly
Font Weight: Varied for hierarchy
```

### Interactive Elements
```
Minimum Touch Target: 44px x 44px
Button Padding: Sufficient space
Focus State: Visible focus indicator (border or outline)
Link Underlines: Recommended or distinguishable color
Hover States: Clear visual feedback
```

### Images
```
All images: Alt text (descriptive, concise)
Complex images: Longer description available
Icons: Role and purpose explained
Decorative images: Alt="" or aria-hidden="true"
```

### Forms
```
Labels: Associated with form fields (for/id)
Error Messages: Linked to form field via aria-describedby
Instructions: Clear, before form field
Required Fields: Marked clearly (asterisk + text)
Validation: Real-time feedback with clear messages
```

### Navigation
```
Keyboard Navigation: Tab through all interactive elements
Focus Order: Logical, follows visual order
Skip Links: Present and functional
Menu Structure: Semantic HTML, ARIA labels where needed
```

## 🚀 IMPLEMENTATION GUIDELINES FOR DEVELOPERS

### CSS Classes Naming Convention
```
BEM Methodology:
Block: .nav, .card, .button
Element: .nav__item, .card__title, .button__icon
Modifier: .button--primary, .card--hover

Example:
.product-card { }
.product-card__icon { }
.product-card__title { }
.product-card--hover { }
```

### CSS Variables (Custom Properties)
```
:root {
  --primary: #0F4C8B;
  --primary-light: #1565C0;
  --secondary: #FF6B35;
  --accent: #4ECDC4;
  --dark: #1a1a1a;
  --light: #F8F9FB;
  --text-dark: #2c3e50;
  --text-light: #7f8c8d;
  --border-color: #e0e6ed;
  
  /* Spacing */
  --spacing-xs: 4px;
  --spacing-sm: 8px;
  --spacing-base: 12px;
  --spacing-md: 16px;
  --spacing-lg: 20px;
  --spacing-xl: 24px;
  --spacing-2xl: 32px;
  
  /* Transitions */
  --transition-fast: all 0.15s ease;
  --transition-normal: all 0.3s ease;
  --transition-slow: all 0.5s ease;
  
  /* Border Radius */
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 12px;
  --radius-full: 50%;
}
```

### Usage Example
```css
.button-primary {
  background: linear-gradient(135deg, var(--primary) 0%, var(--primary-light) 100%);
  color: white;
  padding: var(--spacing-md) var(--spacing-xl);
  border-radius: var(--radius-md);
  transition: var(--transition-normal);
}

.button-primary:hover {
  transform: translateY(-2px);
  box-shadow: 0 4px 15px rgba(15, 76, 139, 0.3);
}
```
