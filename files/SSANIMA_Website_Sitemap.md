## DEVICE BREAKPOINTS & RESPONSIVE DESIGN

### Breakpoints:
- **Desktop:** 1400px+ (Main design target)
- **Laptop:** 1024px - 1399px (Minor adjustments)
- **Tablet:** 768px - 1023px (Stack columns, reduce padding)
- **Mobile:** 320px - 767px (Full vertical stack, touch-friendly)

### Mobile-Specific Changes:
- **Navigation:** Hamburger menu
- **Grids:** Single column layout
- **Images:** Optimized for mobile (smaller file sizes)
- **Buttons:** Larger touch targets (min 44x44px)
- **Typography:** Readable on small screens (min 16px)
- **Forms:** Single column, larger inputs
